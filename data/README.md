# Data setup

This repository intentionally does **not** redistribute the MovieLens 100K raw files. The dataset README supplied by GroupLens states that the data may not be redistributed without separate permission.

Download **MovieLens 100K** from GroupLens, then place these files in `data/raw/ml-100k/`:

- `u.data`
- `u.item`
- `u.user`
- `u.genre`
- `u.info`

The pipeline will create the processed, model, dashboard-export, validation, and figure directories automatically.

Review the usage terms and citation on the GroupLens MovieLens 100K download page before using the dataset.
